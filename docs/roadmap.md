# Roadmap

## Phase 1 — Foundations (this scaffold)
- Clean Architecture solution structure
- Postgres/Supabase connection via EF Core
- Receipts module (CRUD) + REST API
- React/TS/Vite/Tailwind frontend skeleton
- Basic dashboard shell

## Phase 2
- CSV import (Loyverse export)
- Expenses module
- Daily Cash Flow computation
- Daily Cash on Hand / reconciliation logic

## Phase 3
- Attendance (time in/out, OT, holiday OT)
- Payroll / salary cutoff computation
- Employee management

## Phase 4
- Supabase Auth integration + authorization
- Notifications
- Reports
- Inventory, Machine monitoring

## Phase 5
- Direct Loyverse API integration
- Multi-branch support
- Mobile optimization
- Production deployment hardening (lock down RLS, secrets, CI/CD)
